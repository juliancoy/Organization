What each control does

Pause new jobs saves a persistent pause setting. Current work can finish.

Stop swarm work now also stops active swarm worker containers and the Venter QC worker. An interrupted batch may need to run again elsewhere. Saved results are retained.

Resume jobs returns to automatic participation and restarts GPU/QC services stopped by these controls. Battery policy still applies.

An unavailable machine cannot be changed until it reconnects. Status is refreshed every 10 seconds.
