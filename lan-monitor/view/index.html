Measures HTTP application throughput in Mbps and round-trip latency in ms, including browser, server and proxy overhead. Small transfers may underestimate fast links. Particle physics

The viewing device sits at the center. Layout distance does not represent physical distance or network latency.

Link map uses ASUS associations and the Ethernet connection. IP hops uses TTL probes; ASUS is a bridge, not a routed hop. Outer width is the reported link-rate ceiling, not measured available bandwidth. Edge traces show up to two minutes of recent throughput on independent scales. Unmeasured transit links have no trace. Hover or tap for download context; open files and image operations are not proof of payload filenames.

Updates use simple polling. Local discovery runs every 30 seconds; accessible SSH perspectives refresh every five minutes or when you scan.
